# Contributing

Contributions, bug reports, and accessibility improvements are welcome.

## Getting started

Open `index.html` in a modern browser, then press **Start Sound** to enable audio. Test motion controls on compatible devices over HTTPS.

Use Node.js 20 or newer and run:

```sh
npm test
```

## Pull requests

Keep changes focused. Explain behavior changes and test them in desktop and mobile browsers when possible. For audio changes, mention volume safety, browser compatibility, and whether you tested headphones. For motion changes, document permission handling and a pointer/touch fallback.

Do not commit credentials or user data. Contributions are licensed under the existing MIT license.
