# Security Policy

Report security vulnerabilities privately using GitHub's **Report a vulnerability** feature in the Security tab, if enabled. Otherwise contact the maintainer privately. Avoid public disclosure before the issue can be assessed.

Include reproduction steps, browser/device information, impact, and any relevant proof of concept without sensitive information.

This application uses browser audio and motion APIs and saves preferences locally. Treat permission prompts, user gesture requirements, and third-party browser limitations carefully. Security reports do not have a guaranteed response timeline.
